# 2026-11-12 体检整改合同

本次实现对应外部体检方案 F01–F25。源码实现与自动化/合成验证不能替代真实账号、真实清理、升级迁移及不同 macOS 的验收；未自动安装或发布应用。

## 数据与事务

- 新请求采用稳定身份，Token/时间/归属作为可修订属性；后补时间不再生成第二个请求。来源观测顺序防止旧读取覆盖新事实。
- 用量总账新记录进入 `usage-ledger-v2.sqlite`，旧 JSON 作为只读恢复基准保留。无原始用量的金额凭据不生成 Token、请求或固定日期。坏文件、未来结构和写回失败停止提交并保留原件。
- 数据库分批查询之间不保留源库读事务；变化时标记部分结果/重试。单条大 BLOB 投影仍使用有界短事务，保证同一次投影的一致性。
- 未索引、缺父关系、未知状态和归档树受保护；“摘要缺项”不再当作“用户已删除”的证明。会话历史瘦身仍须手动选择、宿主已退出及完整归档回读验证。
- 清理/恢复先同步完整移动计划，再执行原文件、WAL、SHM等移动。崩溃后对照对象身份回滚；有外部变化或宿主运行时保留计划，不覆盖新对象。恢复时位移的新缓存也在反向计划内。

## 历史费用修订

价格资产由模型目录生成并由门禁检查一致性。Gemini 2.5 Flash 的新核价起点为本地核对日期，不能据此推断全部历史价格；旧金额不因同步新表而自动重写。

重估接口先生成具体预览，再用 `previewId` 和明确确认提交；预览后数据或价格变化会拒绝提交。预览包含原费率副本、候选库、前后金额和差异样本；提交后可按同一预览回退，发现后续变化则停止覆盖。源码没有自动替用户执行这些历史修订。

账号归属仅在已观测身份之后有实际时间证据时关联；无时间和历史未知身份不根据 DB mtime 猜测。旧 JSON 的不确定归属保留在只读预览中，不冒充新证据。

## 性能与快照

小账本保留有界快速路径，超过 50,000 条后由 Worker 流式汇总和索引分页，主进程不装载完整历史数组。追加按事件 upsert；未改变的账本复用聚合并续期快照。修订版本保留当前事实及仍被有效快照引用的基线，过期的派生版本可回收复用空间。

私有总账的事务与快照只涉及 GravityBox 自己的索引，不会持有 Antigravity 源库的长期读事务。源库单库记录、旧 JSON 体积及 Worker 时间均有预算，超过预算保留原件并明确报告，不将截断值冒充完整统计。历史价格无法证明适用时保留未知。

## 界面、工具与证据

用量查询身份包含账号、周期和快照；失败保留结果时说明原范围并禁用不匹配导出；成功重试即使数据未变，也恢复状态文案。账号页提供备份入口，敏感备份在写入任何内容之前以 0600 创建。原生更新检查的状态变更在主队列完成，后台回调替身覆盖重叠检查与失败复位。

总览模型 ID 可复制，数字与 HUD 采用相同的先舍入后进位原则；密度由少量语义角色常量管理，保留平台和上下文差异。

验证入口默认不生成新适配输入。新提取使用 TypeScript 公开 AST 接口；免 vendor 模式验证已审阅快照的结构和清单摘要，并明确 `byteVerified: false`。历史正则快照没有因为清单登记就变成“本轮完成了 AST 重提取”，重新取得原始官方字节后才能升级其证据。

自动遍历、词条编辑准备和原生语言偏好保留为开发 API，当前没有对应原生管理页面；不提供在线补译，也不把用户引向不存在的入口。
